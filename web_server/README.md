# web_server

Scripts for transferring files to a server and configuring nginx.

- 0-transfer_file: transfers a file to a server with scp
- 1-install_nginx_web_server: installs nginx and serves a Holberton School page
- 2-setup_a_domain_name: my domain name
- 3-redirection: adds a 301 redirect on /redirect_me
- 4-not_found_page_404: adds a custom 404 page
- 5-design_a_beautiful_404_page.html: a designed 404 page
